# oxido-language

Crate de dominio con fuentes y spans UTF-8, diagnósticos, lexer y parser/AST inicial de Óxido. Reconoce funciones, bloques, declaraciones, control básico y conserva fragmentos Rust; no realiza traducción `.ox → .rs` ni invoca Cargo. Véase el [informe de Fase 4](../../docs/fase-4-parser.md) para alcance y límites.
