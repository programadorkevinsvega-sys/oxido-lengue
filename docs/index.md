# Óxido

Una sintaxis en español e inglés que busca generar Rust estándar y conservar su semántica, interoperabilidad y herramientas.

> **Estado del proyecto:** Óxido está en etapa temprana. Puedes descargar la [versión 0.1.1](https://github.com/programadorkevinsvega-sys/oxido-lengue/releases/tag/v0.1.1), instalar la CLI o la extensión desde los `.deb`, o instalar el VSIX manualmente. La extensión todavía no está publicada en Marketplace. Puedes ejecutar ejemplos, exportar Rust y usar el editor con LSP para el subconjunto documentado. La compatibilidad se limita a la [matriz de compatibilidad](./compatibility). No es un producto listo para producción: la CLI no aísla código de dependencias y el playground solo se verificó en Linux y no está desplegado. Empieza por la [guía de instalación](./instalacion) o el [tutorial](./tutorial).
