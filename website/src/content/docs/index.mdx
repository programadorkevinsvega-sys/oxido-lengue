<Aside type="caution" title="Estado actual">
Óxido tiene lexer, parser y generación de Rust. Las Fases 5–8 están completadas en sus alcances documentados; la Fase 9 está en curso. La CLI incluye `nuevo`, `formato`, `probar` e importación de proyectos, con cobertura de pruebas en ampliación. La compatibilidad sigue limitada a la matriz de características probadas; la CLI no sandboxa código de dependencias y el proyecto no se declara listo para producción. Consulta la [matriz de compatibilidad](/referencia/compatibility/) y el [roadmap](/referencia/roadmap/) para ver las pruebas y límites.
</Aside>
