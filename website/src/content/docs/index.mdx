<Aside type="note" title="Estado actual">
Óxido está en etapa temprana. La [versión 0.1.0 está disponible para descargar](https://github.com/programadorkevinsvega-sys/oxido-lengue/releases/tag/v0.1.0), con paquetes Debian para la CLI y la extensión, además de VSIX por plataforma. El Marketplace todavía no está publicado. Ya puedes ejecutar ejemplos, exportar Rust y usar el editor con LSP. La compatibilidad se limita a la [matriz publicada](/referencia/compatibility/): no es un producto listo para producción y la CLI no aísla código de dependencias. Empieza por la [guía de instalación](/referencia/instalacion/) o el [tutorial progresivo](/referencia/tutorial/).
</Aside>
