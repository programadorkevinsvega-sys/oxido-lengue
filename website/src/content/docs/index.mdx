<Aside type="caution" title="Estado actual">
Óxido tiene lexer, parser y generación de Rust. Las Fases 5–9 están completadas en sus alcances documentados. La Fase 10 está en cierre: cuenta con siete pares diferenciales positivos, regresiones de importación/exportación, fuzzing semanal de 10.000 casos por target, pruebas LSP incrementales y de cancelación, informe de validación descargable y referencias funcionales automatizadas. El benchmark release de cinco rondas y la CI remota de cierre están pendientes; no se afirma aún rendimiento medido. `oxido formato` aplica las convenciones propias de Óxido; el Rust exportado coincide con `rustfmt` 1.99.1 en la matriz de construcciones estructurales admitidas. La CLI incluye `nuevo`, `formato`, `probar` e importación de proyectos. La compatibilidad sigue limitada a la matriz de características probadas; la CLI no sandboxa código de dependencias y el proyecto no se declara listo para producción. Consulta la [matriz de compatibilidad](/referencia/compatibility/) y el [roadmap](/referencia/roadmap/) para ver las pruebas y límites.
</Aside>
